# Linux Networking Commands

## Show IP Address

hostname -I

---

## Display Network Interfaces

ip a

---

## Display Routing Table

ip route

---

## Check Internet Connectivity

ping -c 4 google.com

---

## Ping DNS Server

ping -c 4 8.8.8.8

---

## Display Listening Ports

ss -tuln

---

## Show Network Statistics

ip -s link

---

## Display Hostname

hostname
