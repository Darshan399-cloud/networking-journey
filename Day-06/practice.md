# Practice Tasks

## Task 1

Display your IP address.

Command:

ip addr

---

## Task 2

Display routing table.

Command:

ip route

---

## Task 3

Display interface summary.

Command:

ip -br addr

---

## Task 4

Display all network interfaces.

Command:

ip link

---

## Task 5

Display ARP table.

Command:

ip neigh

---

## Task 6

Display hostname.

Command:

hostname

---

## Task 7

Display IP address only.

Command:

hostname -I

---
