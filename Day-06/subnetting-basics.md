# Subnetting Basics

Subnetting is the process of dividing one large network into multiple smaller networks called subnets.

Subnetting improves:

- Network Performance
- Security
- IP Address Management
- Traffic Control

---

## Why is Subnetting Important?

Instead of one large network with thousands of devices, subnetting creates smaller networks that are easier to manage.

Cloud providers like AWS and Azure use subnetting to organize resources.

---

## Example

Network

192.168.1.0/24

Possible Subnets

192.168.1.0/25

192.168.1.128/25

Each subnet has its own Network Address, Broadcast Address, and usable host range.
