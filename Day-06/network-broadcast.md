# Network Address and Broadcast Address

## Network Address

The first IP address in a subnet.

Example

Network:

192.168.1.0/24

Network Address:

192.168.1.0

---

## Broadcast Address

The last IP address in a subnet.

Example

Broadcast Address:

192.168.1.255

---

## Usable Host Range

First Host:

192.168.1.1

Last Host:

192.168.1.254

---

## Summary

Network Address → First IP

Broadcast Address → Last IP

Usable Hosts → Between Network and Broadcast
