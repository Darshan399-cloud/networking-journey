# Practice Tasks

## Task 1

Check Firewall Status.

Command:

sudo ufw status

---

## Task 2

Enable UFW.

Command:

sudo ufw enable

---

## Task 3

Allow SSH Port.

Command:

sudo ufw allow 22

---

## Task 4

List iptables Rules.

Command:

sudo iptables -L

---

## Task 5

Display Listening Ports.

Command:

ss -tuln

---

## Task 6

Disable UFW.

Command:

sudo ufw disable

---
