# Firewall

A Firewall is a network security system that monitors and controls incoming and outgoing network traffic.

It allows or blocks network traffic based on predefined security rules.

---

## Why Firewall is Important?

- Protects the system from unauthorized access.
- Blocks malicious traffic.
- Improves network security.
- Controls incoming and outgoing connections.

---

## Types of Firewalls

### Packet Filtering Firewall

Filters packets based on IP Address, Port Number, and Protocol.

---

### Stateful Firewall

Tracks active network connections before allowing packets.

---

### Application Firewall

Filters traffic at the application layer (Layer 7).

---

## Real-World Example

A company firewall blocks unauthorized users from accessing internal servers while allowing employees to access company resources.
