# Switch

A Switch is a networking device that connects multiple devices inside a LAN.

It works at the Data Link Layer (Layer 2) of the OSI Model.

---

## How Switch Works

- Uses MAC Address to identify devices.
- Sends data only to the destination device.
- Reduces unnecessary traffic.

---

## Features

- MAC Address Learning
- Better performance than Hub
- More secure communication

---

## Real-World Example

Office networks use switches to connect computers, printers, and servers.
