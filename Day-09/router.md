# Router

A Router is a networking device that connects different networks together.

It works at the Network Layer (Layer 3) of the OSI Model.

---

## How Router Works

- Uses IP Address for communication.
- Transfers data between different networks.
- Selects the best path for packets.

---

## Features

- IP Routing
- Network Connectivity
- Internet Access

---

## Real-World Example

A home Wi-Fi router connects your local network with the Internet.
