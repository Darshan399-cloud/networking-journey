# What is Networking?

Computer Networking is the process of connecting two or more computers or devices so they can communicate and share data.

Examples:

- Sending WhatsApp Messages
- Watching YouTube
- Browsing Websites
- Cloud Computing
- Online Banking

Without networking, computers cannot communicate with each other.

---

## Why Networking is Important?

- File Sharing
- Printer Sharing
- Internet Access
- Cloud Services
- Remote Access
- Online Gaming
- Video Calls

---

## Real World Example

Laptop ---- WiFi Router ---- Internet ---- Google Server

When you open google.com, your laptop sends a request through the router to Google's servers. The server processes the request and returns the webpage.

---

## Advantages

- Fast Communication
- Centralized Data
- Easy Resource Sharing
- Better Security
- Easy Backup
