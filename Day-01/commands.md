# Basic Linux Networking Commands

## Show Hostname

hostname

---

## Show IP Address

hostname -I

---

## Display Network Interfaces

ip a

---

## Display Routing Table

ip route

---

## Test Internet Connection

ping -c 4 google.com

---

## Test DNS

ping -c 4 8.8.8.8

---

## Show Listening Ports

ss -tuln

---

## View DNS Configuration

cat /etc/resolv.conf

---

## View Hosts File

cat /etc/hosts

---

## Show Host Information

hostnamectl
