# DNS (Domain Name System)

DNS stands for Domain Name System.

It translates human-readable domain names into IP addresses.

Example:

www.google.com

↓

142.250.183.110

Without DNS, users would need to remember IP addresses instead of website names.

---

## Why DNS is Important?

- Easy to remember domain names.
- Converts domain names into IP addresses.
- Makes internet browsing easier.

---

## How DNS Works

Step 1

User enters:

www.google.com

---

Step 2

The computer sends a DNS query.

---

Step 3

The DNS Server searches for the IP Address.

---

Step 4

The DNS Server returns the IP Address.

---

Step 5

The browser connects to the web server using the IP Address.
