# Practice Tasks

## Task 1

Display your IP Address.

Command:

hostname -I

---

## Task 2

Display detailed IP information.

Command:

ip addr

---

## Task 3

Display routing table.

Command:

ip route

---

## Task 4

Display network interfaces.

Command:

ip link

---

## Task 5

Check internet connectivity.

Command:

ping -c 4 google.com

---

## Task 6

View DNS configuration.

Command:

cat /etc/resolv.conf

---

## Challenge

1. Write the difference between Public IP and Private IP.
2. List all Private IP address ranges.
3. Identify the class of these IP addresses:
   - 10.1.1.1
   - 172.20.10.5
   - 192.168.1.100
   - 8.8.8.8
