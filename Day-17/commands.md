# Linux VLAN Commands

## Display Network Interfaces

ip link

---

## Display IP Address

ip addr

---

## Display Interface Summary

ip -br link

---

## Display Routing Table

ip route

---

## Show VLAN Information

ip -d link show

---

## Show Specific Interface

ip link show <interface-name>
```
