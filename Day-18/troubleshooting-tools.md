# Network Troubleshooting Tools

## traceroute

Shows the path packets take toward a destination.

Example:

traceroute google.com

---

## tracepath

A Linux utility for tracing the network path to a destination.

Example:

tracepath google.com

---

## nslookup

Queries DNS information.

Example:

nslookup google.com

---

## dig

A detailed DNS query tool.

Example:

dig google.com

---

## ss

Displays socket and network connection information.

Example:

ss -tuln

---

## ip

Used to inspect and manage network interfaces, IP addresses, routes, and other network configuration.

Examples:

ip addr

ip route

ip link
