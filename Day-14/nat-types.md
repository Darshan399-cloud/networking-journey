# Types of NAT

## Static NAT

Maps one Private IP Address to one Public IP Address.

Example:

192.168.1.10 → 203.0.113.10

---

## Dynamic NAT

Maps a Private IP Address to an available Public IP Address from a pool.

---

## PAT (Port Address Translation)

Also called NAT Overload.

Multiple devices share a single Public IP Address by using different Port Numbers.

This is the most common type of NAT used in home and office networks.

---

## Real-World Example

Your home Wi-Fi router uses PAT to allow multiple devices such as laptops, smartphones, and smart TVs to access the Internet through a single Public IP Address.
