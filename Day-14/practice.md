# Practice Tasks

## Task 1

Display your IP Address.

Command:

ip addr

---

## Task 2

Display the Routing Table.

Command:

ip route

---

## Task 3

Display the Default Gateway.

Command:

ip route | grep default

---

## Task 4

Display Network Interfaces.

Command:

ip link

---

## Task 5

Display the ARP Table.

Command:

ip neigh

---

## Task 6

Test Internet Connectivity.

Command:

ping -c 4 google.com
