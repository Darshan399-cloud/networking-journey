# Practice Tasks

## Task 1

Display your IP Address.

Command:

ip addr

---

## Task 2

Display interface summary.

Command:

ip -br addr

---

## Task 3

Display routing table.

Command:

ip route

---

## Task 4

Display network interfaces.

Command:

ip link

---

## Task 5

Display interface statistics.

Command:

ip -s link

---

## Task 6

Display ARP table.

Command:

ip neigh
