# VLSM (Variable Length Subnet Mask)

VLSM stands for Variable Length Subnet Mask.

It allows different subnet sizes based on the number of hosts required.

---

## Advantages

- Better IP address utilization
- Flexible network design
- Used in modern enterprise and cloud networks

---

## Example

Network:

192.168.1.0/24

Subnet 1:

192.168.1.0/25

Subnet 2:

192.168.1.128/26

Subnet 3:

192.168.1.192/27

Each subnet has a different size.
