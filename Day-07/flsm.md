# FLSM (Fixed Length Subnet Mask)

FLSM stands for Fixed Length Subnet Mask.

In FLSM, all subnets have the same subnet mask and the same number of host addresses.

---

## Advantages

- Easy to design
- Simple to manage
- Easy to troubleshoot

---

## Disadvantages

- Wastes IP addresses
- Not suitable for networks with different host requirements

---

## Example

Network:

192.168.1.0/24

Subnets:

192.168.1.0/26

192.168.1.64/26

192.168.1.128/26

192.168.1.192/26

Each subnet has the same size.
