# DHCP (Dynamic Host Configuration Protocol)

DHCP stands for Dynamic Host Configuration Protocol.

It automatically assigns network configuration to devices connected to a network.

DHCP provides:

- IP Address
- Subnet Mask
- Default Gateway
- DNS Server

Without DHCP, users would have to configure these settings manually.

---

## Why DHCP is Important?

- Automatic IP Address Assignment
- Reduces Configuration Errors
- Saves Time
- Easy Network Management

---

## DHCP Components

### DHCP Server

Assigns IP addresses.

---

### DHCP Client

Requests an IP address.

---

### DHCP Lease

The period for which an IP address is assigned to a client.
