# Ports in Computer Networks

A Port is a logical communication endpoint used by applications to send and receive data.

A port works together with an IP Address to identify a specific service running on a device.

Example:

192.168.1.10:80

Here,

IP Address = 192.168.1.10

Port = 80

---

## Port Number Ranges

### Well-Known Ports

0 - 1023

Used by common services.

Examples:

HTTP → 80

HTTPS → 443

FTP → 21

SSH → 22

DNS → 53

SMTP → 25

---

### Registered Ports

1024 - 49151

Used by user applications and registered services.

---

### Dynamic / Private Ports

49152 - 65535

Used temporarily by client applications.
