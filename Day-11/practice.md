# Practice Tasks

## Task 1

Display all listening ports.

Command:

ss -tuln

---

## Task 2

Display active TCP connections.

Command:

ss -tun

---

## Task 3

Display all sockets.

Command:

ss -a

---

## Task 4

Display your IP Address.

Command:

ip addr

---

## Task 5

Test internet connectivity.

Command:

ping -c 4 google.com

## Task 6

Display hostname.

Command:

hostname
