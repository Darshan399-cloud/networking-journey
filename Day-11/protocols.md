# Common Network Protocols

## HTTP

Port: 80

Used for transferring web pages.

Protocol: TCP

---

## HTTPS

Port: 443

Secure version of HTTP.

Protocol: TCP

---

## FTP

Port: 21

Used for file transfer.

Protocol: TCP

---

## SSH

Port: 22

Used for secure remote login.

Protocol: TCP

---

## DNS

Port: 53

Converts domain names into IP addresses.

Protocol: TCP / UDP

---

## DHCP

Ports:

Server → 67

Client → 68

Protocol: UDP

---

## SMTP

Port: 25

Used for sending emails.

Protocol: TCP
