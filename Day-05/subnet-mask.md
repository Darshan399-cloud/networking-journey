# Subnet Mask

A subnet mask is a 32-bit number used to divide an IP address into two parts:

- Network ID
- Host ID

It tells the computer which part of an IP address belongs to the network and which part belongs to the host.

---

## Common Subnet Masks

255.0.0.0

255.255.0.0

255.255.255.0

255.255.255.192

---

## Example

IP Address

192.168.1.20

Subnet Mask

255.255.255.0

Network ID

192.168.1.0

Host ID

20

---

## Why Use Subnetting?

- Better network organization
- Improved security
- Efficient IP address usage
- Reduced network congestion
