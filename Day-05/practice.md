# Practice Tasks

## Task 1

Display your IP address with CIDR notation.

Command:

ip addr

---

## Task 2

Display interface summary.

Command:

ip -br addr

---

## Task 3

Display routing table.

Command:

ip route

---

## Task 4

Display all network interfaces.

Command:

ip link

---

## Task 5

Display hostname.

Command:

hostname

---

## Task 6

Display IP Address.

Command:

hostname -I

---
