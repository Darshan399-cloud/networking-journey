# Practice Tasks

## Task 1

Display your MAC Address.

Command:

ip link

---

## Task 2

Display detailed interface information.

Command:

ip addr

---

## Task 3

Display the ARP table.

Command:

ip neigh

---

## Task 4

Display interface summary.

Command:

ip -br addr

---

## Task 5

Test internet connectivity.

Command:

ping -c 4 google.com

hostname
