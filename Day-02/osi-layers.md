# OSI Layers

## Layer 7 - Application

Provides network services to applications.

Examples:
- HTTP
- HTTPS
- FTP
- SMTP

---

## Layer 6 - Presentation

Responsible for:
- Encryption
- Compression
- Data Translation

---

## Layer 5 - Session

Creates, manages, and terminates communication sessions.

---

## Layer 4 - Transport

Responsible for:
- End-to-end communication
- Error checking
- Reliable delivery

Protocols:
- TCP
- UDP

---

## Layer 3 - Network

Responsible for routing.

Uses:
- IP Address
- Routers

Protocol:
- IP

---

## Layer 2 - Data Link

Responsible for:
- MAC Address
- Error Detection
- Frame Delivery

Device:
- Switch

---

## Layer 1 - Physical

Responsible for transmitting bits through cables or wireless media.

Examples:
- Ethernet Cable
- Fiber Optic Cable
- Wi-Fi
